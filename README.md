# Sistema de Gestión de Citas Médicas (FullStack MEVN)

Aplicación web integral para la gestión, reserva y administración de citas. Este proyecto demuestra la capacidad de desarrollar soluciones de extremo a extremo (End-to-End) utilizando el stack moderno de JavaScript.

## 🚀 Stack Tecnológico (MEVN)

*   **Frontend:** Vue.js (Framework progresivo para interfaces dinámicas)
*   **Backend:** Node.js con Express.js (Arquitectura de microservicios)
*   **Base de Datos:** MongoDB (Persistencia NoSQL)
*   **Gestión de Estados:** Vuex / Composition API
*   **Estilos:** CSS3 / Bootstrap o Tailwind

## 🏗️ Funcionalidades Clave

*   **Arquitectura Desacoplada:** Separación clara entre el Frontend (Vue) y el Backend (Node/Express) mediante una API RESTful.
*   **CRUD Completo:** Gestión dinámica de pacientes, médicos y horarios de atención.
*   **Persistencia Real-Time:** Integración con MongoDB para el manejo de documentos y disponibilidad de citas sin conflictos de concurrencia.
*   **Diseño Responsivo:** Interfaz adaptada para dispositivos móviles y escritorio.

## 🛠️ Instalación Rápida

1. **Backend:** Entrar a `/backend`, ejecutar `npm install` y luego `npm start`.
2. **Frontend:** Entrar a `/frontend`, ejecutar `npm install` y luego `npm run serve`.
